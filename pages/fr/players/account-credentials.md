# Pseudo, e-mail et mot de passe

> **En bref** : vous changez votre **pseudo**, votre **adresse e-mail** et votre **mot de passe** vous-même, dans les Paramètres, onglet **Compte**. Chaque changement demande votre **mot de passe actuel**. Le pseudo est gratuit, une fois tous les **7 jours**, et c'est aussi votre identifiant de connexion. Une nouvelle adresse se confirme par un **code de 6 chiffres**, valable **30 minutes**, une fois toutes les **24 heures**. Un nouveau mot de passe ferme vos **autres sessions**.
{.is-info}

## Règles

### Pour chaque changement
1. Tout se passe dans les **Paramètres**, onglet **Compte**, bloc « Identifiants » : un bouton « Modifier » à côté du pseudo, de l'adresse e-mail et du mot de passe.
2. Chaque changement demande votre **mot de passe actuel**. Une session restée ouverte sur un autre appareil ne suffit donc pas à prendre votre compte.
3. Après trop de tentatives, il faut patienter quelques minutes avant de réessayer.
4. **Pendant les 7 jours d'une [suppression de compte](/fr/players/account-deletion)**, rien ne peut être changé : ni pseudo, ni adresse, ni mot de passe. Annulez d'abord la suppression.

### Le pseudo
5. Changer de pseudo est **gratuit**, au plus **une fois tous les 7 jours**. Le premier changement est possible à tout moment ; ensuite, l'onglet Compte affiche la date du prochain.
6. Le nouveau pseudo suit les règles de l'inscription : **5 à 50 caractères**, sans espace. Il ne doit être ni pris par un autre compte, ni réservé.
7. Votre pseudo est aussi votre **identifiant de connexion** : dès le changement, vous vous connectez avec le nouveau, l'ancien ne fonctionne plus. Un mail vous rappelle le nouveau pseudo.
8. Pendant **30 jours**, votre profil affiche « Anciennement » suivi de votre ancien pseudo, et **personne d'autre ne peut le prendre**. Vous pouvez le reprendre vous-même pendant ces 30 jours, si les 7 jours depuis votre dernier changement sont passés.
9. Les rapports déjà écrits gardent l'ancien pseudo. Pendant ces 30 jours, cliquer dessus **ouvre toujours votre profil**, sous votre nouveau pseudo.
10. Changer seulement les majuscules et minuscules (par exemple `vega` en `Vega`) compte comme un changement pour le délai de 7 jours, mais rien n'est réservé ni affiché comme ancien pseudo.
11. Vos sessions restent ouvertes : changer de pseudo ne déconnecte aucun appareil.

### L'adresse e-mail
12. Vous saisissez la nouvelle adresse et votre mot de passe actuel : un **code de 6 chiffres** part vers la **nouvelle adresse**. Il reste valable **30 minutes**.
13. Tant que le code n'est pas saisi, votre **adresse actuelle reste celle du compte**, pour tous les mails, y compris ceux du mot de passe oublié. L'onglet Compte rappelle l'adresse en attente, l'heure limite du code, et propose « Saisir le code ».
14. Le code n'est pas arrivé ? « Je n'ai rien reçu : renvoyer un code » envoie un nouveau code, qui remplace le précédent. Un code expiré ne sert plus : il faut recommencer.
15. Une fois le code saisi, la nouvelle adresse devient celle du compte, et l'**ancienne adresse reçoit un dernier mail** qui la prévient du changement et donne la nouvelle.
16. Il faut attendre **24 heures** entre deux changements d'adresse. L'onglet Compte affiche la date du prochain.
17. Une adresse déjà utilisée par un autre compte ne peut pas être prise.

### Le mot de passe
18. Vous saisissez le mot de passe actuel, puis le nouveau deux fois : **5 caractères au moins**, différent de l'actuel.
19. Par sécurité, **toutes vos autres sessions sont fermées** : sur vos autres appareils et navigateurs, il faut vous **reconnecter** avec le nouveau mot de passe. L'appareil qui a fait le changement reste connecté.
20. Un mail vous confirme le changement. Il part aussi après une réinitialisation par « Mot de passe oublié ? ».

## Exemple chiffré

Le 27 octobre à 14:00, vous passez de `Rigel` à `Vega` :
- vous vous connectez désormais avec `Vega` ;
- prochain changement de pseudo possible le **3 novembre à 14:00** ;
- jusqu'au **26 novembre à 14:00**, votre profil affiche « Anciennement Rigel », personne d'autre ne peut prendre `Rigel`, et un ancien rapport qui nomme `Rigel` mène à votre profil.

Le même jour à 14:05, vous demandez une nouvelle adresse :
- le code envoyé à la nouvelle adresse vaut jusqu'à **14:35** ;
- vous le saisissez à 14:12 : la nouvelle adresse devient celle du compte, l'ancienne reçoit le mail de prévention ;
- prochain changement d'adresse possible le **28 octobre à 14:12**.

## Pièges fréquents

- **Notez votre nouveau pseudo** : c'est lui qu'il faut saisir pour vous connecter. Le mail de confirmation le rappelle.
- **Le code part vers la nouvelle adresse**, pas vers l'actuelle : vérifiez qu'elle est bien écrite et regardez dans les indésirables.
- **Changer de mot de passe déconnecte vos autres appareils**, téléphone compris : prévoyez de vous y reconnecter.
- **Un changement de majuscules lance aussi le délai de 7 jours.**
- **Un mail que vous n'attendiez pas** (pseudo, adresse ou mot de passe modifié) : changez votre mot de passe, ou utilisez « Mot de passe oublié ? » si vous ne pouvez plus vous connecter, puis écrivez au support.
